## Other Merges

* kubectl kustomize [no longer loads kustomize Go (`.so`) plugins](https://github.com/kubernetes/kubernetes/pull/142791); exec and KRM function plugins are unaffected
* Updated TokenReview internal type to [improve cast speed from latest external version](https://github.com/kubernetes/kubernetes/pull/142750)
* Strengthened [runtime PodGroup and CompositePodGroup hierarchy validation in kube-scheduler](https://github.com/kubernetes/kubernetes/pull/142719) to verify maximum tree depth, Workload reference consistency, scheduling policies, and disruption modes
* applyconfiguration-gen now honors [`+k8s:openapi-model-package` when looking up OpenAPI definitions](https://github.com/kubernetes/kubernetes/pull/142697), and fails if the schema has no definition for a root type
* kube-apiserver and other servers built on k8s.io/apiserver now [accept up to 16384 request header values](https://github.com/kubernetes/kubernetes/pull/142607)
* API server now returns [400 instead of 500 status code](https://github.com/kubernetes/kubernetes/pull/142591) on GET request with invalid revision
* Fixed[ API warnings on ReplicationController updates](https://github.com/kubernetes/kubernetes/pull/142443), which described the previous pod template instead of the new one
* DRA consumable capacity + CEL: [fixed name comparisons and lookup](https://github.com/kubernetes/kubernetes/pull/142202)
* Fix: [kubectl create ingress panics on rules with extra equals signs](https://github.com/kubernetes/kubernetes/pull/142640)
* kubectl: [keep a multi-line event message inside its table row](https://github.com/kubernetes/kubernetes/pull/142149)
* ktesting: the former internal packages are now [available as k8s.io/ktesting and k8s.io/client-go/ktesting](https://github.com/kubernetes/kubernetes/pull/142146)
*  DRA: [fixed a deadlock](https://github.com/kubernetes/kubernetes/pull/141108) when an `ErrorHandler` calls `Update`, or a kubelet plugin's `HandleError` calls `PublishResources`, in response to pools that do not match `ReconcilePoolWithName`
* Added `percentageOfPlacementsToScore` [to the scheduler config](https://github.com/kubernetes/kubernetes/pull/139859)
* Strengthened [runtime PodGroup and CompositePodGroup hierarchy validation](https://github.com/kubernetes/kubernetes/pull/142719) in kube-scheduler to verify maximum tree depth, workload reference consistency, scheduling policies, and disruption modes
* The deployment controller now [retries when scaling down an old ReplicaSet fails during a rolling update](https://github.com/kubernetes/kubernetes/pull/142650), instead of treating that failure as success
* The metrics `apiserver_resource_size_estimate_bytes` and `apiserver_resource_objects` now [include explicit observation timestamps](https://github.com/kubernetes/kubernetes/pull/142007)
* Added [conditional authorization support to kube-apiserver](https://github.com/kubernetes/kubernetes/pull/137633)

## Subprojects and Dependency Updates

* [nerdctl v2.4.1](https://github.com/containerd/nerdctl/releases/tag/v2.4.1): Fixes CDI support in compose, fixes port forwarding on Windows, and updates bundled containerd to 2.4.1
