## Other Merges

* Fixed [refcounting leak in the node authorizer graph](https://github.com/kubernetes/kubernetes/pull/142574) for pods which reference secrets, configmaps, or pvcs multiple times
* Fixed [`kubectl kuberc set` leaving a stale credential plugin allowlist](https://github.com/kubernetes/kubernetes/pull/142564) when the policy is changed to AllowAll or DenyAll, which caused kubectl to fail
* Added [consistency store to client-go](https://github.com/kubernetes/kubernetes/pull/142537) and deprecated it from pkg/controller
* Fixed k8s.io/apimachinery/pkg/util/yaml [silently dropping the last line of a YAML stream](https://github.com/kubernetes/kubernetes/pull/142527) when it has no trailing newline and its length is an exact multiple of the reader buffer size
* Separated [deleteGet and updateGet etcd operation in etcd_request_* metrics](https://github.com/kubernetes/kubernetes/pull/142484) and added reason label to error
* kubelet: the pods API gRPC server now [limits concurrent streams per connection to 100](https://github.com/kubernetes/kubernetes/pull/142458) and applies its request rate limit to WatchPods stream openings
* kubelet: [gRPC probes fail immediately when the connection is refused](https://github.com/kubernetes/kubernetes/pull/142457) instead of retrying until the probe timeout
* `kubectl label` now [prints messages about nonexistent labels to stderr instead of stdout](https://github.com/kubernetes/kubernetes/pull/142436), so they no longer break JSON or YAML output
* hack/local-up-cluster.sh now [supports quantum crypto keys and certs for testing](https://github.com/kubernetes/kubernetes/pull/142401)
* Kubelet now [reports allocated resource health statuses in deterministic order](https://github.com/kubernetes/kubernetes/pull/142340), preventing unnecessary Pod status updates when resource health is unchanged
* Fixed the [HorizontalPodAutoscaler utilization and usage calculations wrapping to a wrong or negative current value](https://github.com/kubernetes/kubernetes/pull/142192) when pod metric or request totals exceeded int64 or the utilization percentage exceeded int32; the reported percentage now saturates at the int32 limit
* Fixed the [`taint_eviction_controller_pod_deletion_duration_seconds` metric](https://github.com/kubernetes/kubernetes/pull/141742), which recorded nanoseconds scaled by 1e9 instead of seconds
* Creating or updating a resource.k8s.io object [with a qualified name that contains more than one slash, such as a device attribute key `a/b/c`, is now rejected](https://github.com/kubernetes/kubernetes/pull/141644)
* Added [CloudNodeAdditionalLabelsReconciliation feature gate](https://github.com/kubernetes/kubernetes/pull/141616)
* [Fixed the field path in CSIDriver validation errors](https://github.com/kubernetes/kubernetes/pull/141597) for `spec.attachRequired`, which was previously reported as `spec.attachedRequired` — a field that does not exist in the API
* kube-controller-manager: [informer metrics now use correctly pluralized resource names](https://github.com/kubernetes/kubernetes/pull/141566)
* kubelet: fixed [invalid user range selection for user namespaces](https://github.com/kubernetes/kubernetes/pull/141345)
* Fixed the [ResourceClaim controller repeatedly restoring terminal Pod entries in `status.reservedFor`](https://github.com/kubernetes/kubernetes/pull/141276) for allocated claims that remain in use by other consumers
* Fixed ResourceSlice validation to [reject a per-device `nodeSelector` with more than one node selector term](https://github.com/kubernetes/kubernetes/pull/141213), as it already does for the slice-level `nodeSelector`
* Fixed a panic in `kubectl kuberc view` when [no kuberc file exists and the user declines to generate a default one](https://github.com/kubernetes/kubernetes/pull/141099)
* Fixed kubelet so that pods using `dnsPolicy: Default` [no longer inherit scoped IPv6 link-local nameservers](https://github.com/kubernetes/kubernetes/pull/140880) from the node resolver configuration unless the pod uses the host network namespace
* Fixed [`equality.Semantic.DeepDerivative` for slices by rejecting prefix-only matches](https://github.com/kubernetes/kubernetes/pull/137264)
* Fixed [JSONSchemaProps comment to properly render JSON Schema URL](https://github.com/kubernetes/kubernetes/pull/136159) as a valid link
