## Featured PRs

### [143463: KEP-5710: Log error when PostFilter plugin does not implement PodGroupPostFilterPlugin](https://github.com/kubernetes/kubernetes/pull/143463)

[jdzikowski](https://github.com/jdzikowski) added a scheduler initialization check for plugins that implement `PostFilter` but not `PodGroupPostFilterPlugin`, as part of [KEP-5710](https://github.com/kubernetes/enhancements/issues/5710). With the `GenericWorkload` feature gate enabled, the scheduler now logs an error when an enabled plugin will be skipped during scheduling for a PodGroup or CompositePodGroup. Previously, this behavior could go unnoticed, potentially leaving workload-aware scheduling integrations without the expected post-filtering behavior. The check also fulfills one of the KEP's graduation criteria for General Availability.

### [143387: KEP-5491: Adds integration and e2e test for List Type Attributes](https://github.com/kubernetes/kubernetes/pull/143387)

[everpeace](https://github.com/everpeace) added integration and end-to-end tests for list-typed `matchAttribute` and `distinctAttribute` constraints in Dynamic Resource Allocation (DRA), as specified by [KEP-5491](https://github.com/kubernetes/enhancements/issues/5491). The tests exercise allocation against a real API server and scheduler, covering intersecting and disjoint attribute lists, scalar-to-list matching, and distinctness constraints. These cases help verify that device allocation behaves correctly across different attribute combinations and provide coverage required by the KEP's test plan for beta promotion in Kubernetes v1.38.

## KEP of the Week

### [KEP-6268: Stall and Resume Slow Watch Streams](https://github.com/kubernetes/enhancements/blob/master/keps/sig-api-machinery/6268-watch-cache-stall-resume/README.md)

A slow watch client can fill its kube-apiserver buffer, delaying other watchers
before the server force-closes its stream. KEP-6268 instead marks that watcher
unsynced, catches it up from shared watch-cache history, and resumes it on the
same connection. If the needed events have aged out, the server sends
`410 Gone`. Clients and the API need no changes.

[@nami-ant](https://github.com/nami-ant) and
[@rpb-ant](https://github.com/rpb-ant) authored the KEP for SIG API Machinery.
They revised the design in September to share catch-up work across watchers,
following etcd's model. The
[KEP merged October 1](https://github.com/kubernetes/enhancements/pull/6269),
while the
[kube-apiserver implementation](https://github.com/kubernetes/kubernetes/pull/141450)
remains under review behind the off-by-default `WatchCacheStallResume` gate.
KEP-6268 is `implementable` and targets Alpha in v1.38;
[Beta and Stable milestones are TBD](https://github.com/kubernetes/enhancements/issues/6268).

## Other Merges

* Fix for a [kubelet bug](https://github.com/kubernetes/kubernetes/pull/141014) that set pod sandbox CPU and memory limits to the partial sum of container limits when only some containers declared them
* kube-scheduler's preemption disruption metric [gains a victim label](https://github.com/kubernetes/kubernetes/pull/142955); PreemptionVictim gains a Type() method and PreemptionCandidate.NumPodGroupDisruptions() is replaced by NumDisruptionsByVictimType()
* MutatingAdmissionWebhook config gains a [staticOrder field](https://github.com/kubernetes/kubernetes/pull/143160) to control manifest vs. API-registered webhook ordering; requires the ManifestBasedAdmissionControlConfig gate and must be removed before downgrading to v1.37 or earlier
* A new [evictionrequest-controller](https://github.com/kubernetes/kubernetes/pull/137133) creates Evictions from EvictionRequests and coordinates external responders
* Add [cgroup_mount_mode to the CRI API](https://github.com/kubernetes/kubernetes/pull/139824) to support writable cgroups
* kubectl selector commands like [create pdb --selector](https://github.com/kubernetes/kubernetes/pull/142216) now accept !=
* client-go adds [DropManagedFields](https://github.com/kubernetes/kubernetes/pull/142695) to omit managedFields from API responses, behind the new alpha ManagedFieldsOptOutClient gate
* kubelet adds the alpha [kubelet_device_plugin_devices](https://github.com/kubernetes/kubernetes/pull/143223) metric, breaking device counts down by health state
* Watch cache [keeps the last snapshot behind the compaction window](https://github.com/kubernetes/kubernetes/pull/143325), avoiding etcd fallback for Exact LIST
* Workload-aware scheduling: Pod scheduling status [now names its parent PodGroup](https://github.com/kubernetes/kubernetes/pull/143184) and [PlacementFeasible counts](https://github.com/kubernetes/kubernetes/pull/143183) are clearer, stricter [CompositePodGroup validation](https://github.com/kubernetes/kubernetes/pull/142830), [recursive status propagation](https://github.com/kubernetes/kubernetes/pull/141860), nodes with [empty topology label values skipped](https://github.com/kubernetes/kubernetes/pull/140308) as placement domains, [multiple placement plugins intersected](https://github.com/kubernetes/kubernetes/pull/139565), and TopologyAwareWorkloadScheduling [promoted to Beta](https://github.com/kubernetes/kubernetes/pull/140295) (still disabled by default)
