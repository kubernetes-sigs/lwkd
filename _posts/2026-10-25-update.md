## Developer News

SIG ContribEx has [updated the repo creation guidelines](https://github.com/kubernetes/community/pull/9232) and the [WG governance document](https://github.com/kubernetes/community/pull/9228) to clarify how Working Groups relate to code ownership and repository creation, giving future WG proposals a clearer path from charter to code.

SIG Architecture has [added notes on future conformance](https://github.com/kubernetes/community/pull/9227) in the developer guide, outlining how upcoming conformance work (including the newly formed WG Workload Conformance) will relate to existing conformance definitions.

SIG ContribEx is [coordinating KubeCon EU 2027 Project Pavilion and PR participation](https://groups.google.com/a/kubernetes.io/g/dev/c/WH4G2t9VAUw) for SIGs, WGs, Committees, and Subprojects; interested groups should submit the registration form by November 25.

The [Maintainer Summit NA 2026 unconference](https://groups.google.com/a/kubernetes.io/g/dev/c/hzQyj4rw3Yg) is accepting topic ideas; sessions are open community-led discussions and need only a topic, a note-taker, and a facilitator attending in Salt Lake City.

The SIG Scheduling leadership change proposed last week has [taken effect after lazy consensus closed on October 26](https://groups.google.com/a/kubernetes.io/g/dev/c/X-OG8zIphH8): Heba Elayoty is now a SIG Chair, Matt Matejczyk is a SIG Tech Lead, and Kensei Nakada has stepped down from Chair while remaining a Tech Lead.

## Featured PRs

### [143463: KEP-5710: Log error when PostFilter plugin does not implement PodGroupPostFilterPlugin](https://github.com/kubernetes/kubernetes/pull/143463)

[jdzikowski](https://github.com/jdzikowski) added a scheduler initialization check for plugins that implement `PostFilter` but not `PodGroupPostFilterPlugin`, as part of [KEP-5710](https://github.com/kubernetes/enhancements/issues/5710). With the `GenericWorkload` feature gate enabled, the scheduler now logs an error when an enabled plugin will be skipped during scheduling for a PodGroup or CompositePodGroup. Previously, this behavior could go unnoticed, potentially leaving workload-aware scheduling integrations without the expected post-filtering behavior. The check also fulfills one of the KEP's graduation criteria for General Availability.

### [143387: KEP-5491: Adds integration and e2e test for List Type Attributes](https://github.com/kubernetes/kubernetes/pull/143387)

[everpeace](https://github.com/everpeace) added integration and end-to-end tests for list-typed `matchAttribute` and `distinctAttribute` constraints in Dynamic Resource Allocation (DRA), as specified by [KEP-5491](https://github.com/kubernetes/enhancements/issues/5491). The tests exercise allocation against a real API server and scheduler, covering intersecting and disjoint attribute lists, scalar-to-list matching, and distinctness constraints. These cases help verify that device allocation behaves correctly across different attribute combinations and provide coverage required by the KEP's test plan for beta promotion in Kubernetes v1.38.
