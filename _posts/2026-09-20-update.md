## Subprojects and Dependency Updates

Mostly good, but I caught two issues:

**1. Prometheus "also" is wrong — different weeks.** v3.15.0-rc.0 was released "last week" but v3.13.3 was released "2 weeks ago" per the document. The "also" convention is for same-week backports, not older releases from a prior week. v3.13.3 shouldn't be in this entry at all — it presumably would have been covered in a previous week's LWKD already.

**2. containerd API v1.12.0 bundled as "also" is questionable.** It's not really a version of the *same* release train (it's a separate versioned artifact, the API submodule), even though it ships alongside containerd 2.4.0. Worth a judgment call: either give it its own bullet (as I did in an earlier turn with the beta/rc), or drop it since its changes substantially overlap with what's already summarized in the main containerd bullet (UpdateSandbox RPC, deprecation of the mount-handlers annotation).

Corrected version:

# Subprojects and Dependency Updates

* [containerd v2.4.0](https://github.com/containerd/containerd/releases/tag/v2.4.0): remove restore in CreateContainer, remove deprecated CRI/tracing config options, enable mount manager for image mounts in CRI
* [containerd API v1.12.0](https://github.com/containerd/containerd/releases/tag/api%2Fv1.12.0): align with containerd 2.4.0, deprecate task API address/version fields in runc options
* [cri-o v1.37.0](https://github.com/cri-o/cri-o/releases/tag/v1.37.0): fix CVE-2026-15809, add conmon-rs v1.0.1 support, remove insecure_registries config option
* [prometheus v3.15.0-rc.0](https://github.com/prometheus/prometheus/releases/tag/v3.15.0-rc.0): deprecate --log.level in favor of runtime.log_level, add Unix Domain Socket scrape support, stabilize XOR2 float chunk encoding
* [nerdctl v2.4.0](https://github.com/containerd/nerdctl/releases/tag/v2.4.0): adopt Docker v29 default images output, add --mount type=image, add Docker v25 recursive read-only mount support
