## Other Merges

* ResourceQuota updates [no longer fail validation on a `spec.hard`, `status.hard` or `status.used` value that the object already holds](https://github.com/kubernetes/kubernetes/pull/142190).

* LimitRanger [no longer rejects an update of a PersistentVolumeClaim](https://github.com/kubernetes/kubernetes/pull/142170) because of a request that the update leaves unchanged, even when that request is outside the LimitRange minimum or maximum.

* Fixed issue where [HorizontalPodAutoscaler incorrectly included pod overhead in the request calculation](https://github.com/kubernetes/kubernetes/pull/142154) for pods using pod-level resources.

* client-go: [add support for ML-DSA keys from the crypto/mldsa package of Go 1.27](https://github.com/kubernetes/kubernetes/pull/142038)

* kube-proxy [no longer tries to set the `nf_conntrack_max` sysctl](https://github.com/kubernetes/kubernetes/pull/142035) if its value is already higher than the value kube-proxy wants it to be.

* CEL cost estimation for CRD validation rules using URL accessor functions (getScheme, getHostname, getHost, getPort, getEscapedPath, getQuery) now [propagates the result size bound from the input URL](https://github.com/kubernetes/kubernetes/pull/141984). 

* Fixed [duplicate initialization of serviceaccounts](https://github.com/kubernetes/kubernetes/pull/141892) REST storage when ServiceAccountIssuer is configured

* `kubectl` now prints a [warning when creating or updating a `DeviceTaintRule`](https://github.com/kubernetes/kubernetes/pull/141831) whose `deviceSelector` is present but empty, since that selector matches every device from every driver in the cluster.

* Fix: [silently dropped DNS resolution latency metric](https://github.com/kubernetes/kubernetes/pull/141493) in restclient

* Fixed [issue where a container that was recreated while the kubelet could not reach the API server](https://github.com/kubernetes/kubernetes/pull/141487) was reported Ready after a kubelet restart, before its own readiness probe had run.

* Conformance test `Pods, completes the lifecycle of a Pod and the PodStatus` now [cover resetting the `PodReadyToStartContainers` condition](https://github.com/kubernetes/kubernetes/pull/141460).

* kubelet: [fixed wrong variable in container memory resize validation](https://github.com/kubernetes/kubernetes/pull/141100)

* Added [auto complete support](https://github.com/kubernetes/kubernetes/pull/140058) to kubectl explain

* Fixed [kubectl describe service printing "+ 0 more..." after the endpoint list](https://github.com/kubernetes/kubernetes/pull/142214) when exactly three ready endpoints are followed by not-ready endpoints.

* kubectl debug: The sysadmin profile now [auto-detects Windows nodes and configures debug pods as Windows Host Process Containers](https://github.com/kubernetes/kubernetes/pull/138182) with NT AUTHORITY\SYSTEM access.
