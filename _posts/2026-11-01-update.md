## Featured PRs

### [143644: Update volume health APIs as per newest version of KEP](https://github.com/kubernetes/kubernetes/pull/143644)

[gnufied](https://github.com/gnufied) updated Kubernetes volume health APIs to align with the latest design in [KEP-1432](https://github.com/kubernetes/enhancements/issues/1432), with related changes discussed in [KEP-6395](https://github.com/kubernetes/enhancements/issues/6395). The change moves `volumeHealth` from `PodStatus` into `PodStatus.VolumeStatus` and introduces `Healthy` and `Unknown` values for volume health conditions in the core API and `CSINode` types. It also clarifies how readers and writers should handle new condition values, helping maintain compatibility as volume health reporting evolves. These API changes establish a clearer contract for reporting storage health across Kubernetes and CSI drivers.

### [143701: KEP-5502: Run EmptyDirVolumeMode e2e tests in alpha/beta kind jobs](https://github.com/kubernetes/kubernetes/pull/143701)

[blackjid](https://github.com/blackjid) fixed the test selection for `EmptyDirVolumeMode` end-to-end tests so they can run in the alpha/beta Kind jobs. The tests were being excluded because the additional `[Feature:EmptyDirVolumeMode]` label conflicted with the jobs' `OffByDefault` feature filter, and no other job selected them. This change removes the redundant label while retaining `framework.WithFeatureGate(...)`, allowing the tests to run in CI and build a test history ahead of the feature's beta promotion. The work supports [KEP-5502](https://github.com/kubernetes/enhancements/issues/5502).
