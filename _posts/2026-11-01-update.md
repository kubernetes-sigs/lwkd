## Other Merges

* [cel-go upgraded to v0.33.0](https://github.com/kubernetes/kubernetes/pull/143439), now imported as cel.dev/cel-go; Go code passing cel-go types to k8s.io/apiserver, apiextensions-apiserver or dynamic-resource-allocation must update imports
* CRD types and clients [move to the new k8s.io/apiextensions-api module](https://github.com/kubernetes/kubernetes/pull/142746), with deprecated aliases left in apiextensions-apiserver
* kube-apiserver adds [conditional authorization support](https://github.com/kubernetes/kubernetes/pull/141959)
* client-go leader election adds [write-gating and leader recovery](https://github.com/kubernetes/kubernetes/pull/143289)
* The locked GA [SupplementalGroupsPolicy feature gate is removed](https://github.com/kubernetes/kubernetes/pull/142093); remove it from component configuration before upgrading
* StatefulSet maxUnavailable [no longer counts unavailable pods below the partition](https://github.com/kubernetes/kubernetes/pull/143114) against the update budget
* Decoding JSON lists into UnstructuredList [uses about half the memory](https://github.com/kubernetes/kubernetes/pull/142575) and a third less time
* New [WatchFromStorageWithoutPrevKV feature gate](https://github.com/kubernetes/kubernetes/pull/131862) enables etcd watches without prev-kv
* kubelet adds [kubelet_sync_result_errors_total and kubelet_pod_worker_errors_total](https://github.com/kubernetes/kubernetes/pull/143284) metrics for pod sync errors
* DRA capacity requests [now reject negative quantities, invalid names, and more than 32 entries](https://github.com/kubernetes/kubernetes/pull/143287)
