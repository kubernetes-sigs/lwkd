## Release Schedule

**Kubernetes v1.37: Garhwal** has been released on 26th August! The [Release Announcement](https://kubernetes.io/blog/2026/08/26/kubernetes-v1-37-release/) and [Release Notes](https://github.com/kubernetes/kubernetes/blob/master/CHANGELOG/CHANGELOG-1.37.md) are now available. A few contributor-focused changes worth calling out:
- [StatefulSet Recreate strategy](https://www.kubernetes.dev/resources/keps/3541/) — This KEP adds a new rollout strategy that deletes the existing Pods before creating the updated ones, giving StatefulSet workloads another option beyond RollingUpdate and OnDelete.
- [DRA improvements](https://www.kubernetes.dev/resources/keps/5517/) — v1.37 adds Alpha support for node-allocatable resource requests and derived attributes [(KEP-6080)](https://www.kubernetes.dev/resources/keps/6080/), making it easier for DRA drivers and workloads to account for resources and match related devices.
- [Pod-level checkpoint and restore](https://www.kubernetes.dev/resources/keps/5823/) — This KEP introduces Alpha support for checkpointing and restoring Pods through new CRI APIs.
- [cAdvisor-less container and Pod stats](https://www.kubernetes.dev/resources/keps/2371/) — This moves kubelet container and Pod statistics toward the CRI, reducing reliance on cAdvisor and moving Kubernetes closer to a single source for these metrics.

Starting with v1.38, the release cycle will also have more time between Enhancements Freeze and Code Freeze, giving contributors more time to get their work reviewed and merged and helping reduce the need for Code Freeze exceptions.
