## Developer News
Two security advisories were published on September 24: [CVE-2026-2270](https://groups.google.com/g/kubernetes-announce/c/gI9iatwmRbA) (rated Medium, 5.9) describes a confused deputy attack in the StatefulSet controller that lets a user with namespace-scoped write permissions on `StatefulSet` and `ControllerRevision` objects create a cross-namespace pod, and [CVE-2026-76654](https://groups.google.com/g/kubernetes-announce/c/ZN4CNe2li2w/) (rated Medium, 5.8) describes an NTLM coercion vulnerability on Windows nodes when a pod's `subPath` is a symbolic link to an attacker-controlled UNC network share; both are fixed in the September patch releases (v1.34.12, v1.35.9, v1.36.5, v1.37.1) covered in the Release Schedule below.

SIG Cluster Lifecycle has a [leadership change](https://groups.google.com/a/kubernetes.io/g/dev/c/GmQ3XGyRS4Q): Vince Prignano ([@vincepri](https://github.com/vincepri)) is stepping down as chair, and existing Tech Lead Fabrizio Pandini ([@fabriziopandini](https://github.com/fabriziopandini)) will assume the chair role in addition to his Tech Lead responsibilities. The change is under a one-week lazy consensus period.

## Other Merges
* [Fixed a regression in v1.38](https://github.com/kubernetes/kubernetes/pull/142395) where resource quantities written by a v1.37 or older apiserver with a decimal exponent outside the int32 range could not be decoded, failing reads of the whole collection.
* validation-gen: [`+k8s:minimum` and `+k8s:maximum` support `time.Duration` fields with quoted Go duration strings](https://github.com/kubernetes/kubernetes/pull/142368), such as `+k8s:minimum="1s"`. Integer payloads on `time.Duration` fields are now rejected.
* `SelfSignedCertKeyOptions` in `k8s.io/client-go/util/cert` accepts a `KeyGenerator`, [allowing self-signed certificates to be generated with a key algorithm other than RSA](https://github.com/kubernetes/kubernetes/pull/142350). The default remains a 2048-bit RSA key.
* Added [resource version](https://github.com/kubernetes/kubernetes/pull/142327) to pod binding API
* Fixed a bug where [`NoExecute` device taints (`DeviceTaintRule`) did not evict pods using DRA-backed extended resources](https://github.com/kubernetes/kubernetes/pull/142289) (`pod.Status.ExtendedResourceClaimStatus`)
* resource.Quantity: calling String or encoding a quantity is [now guaranteed to not mutate the instance](https://github.com/kubernetes/kubernetes/pull/142277)
* client-go: [restrict CA key encipherment usage to RSA keys](https://github.com/kubernetes/kubernetes/pull/142273). Key encipherment usage is no longer included for non RSA keys in self signed CA certificates generated from client-go
* Fixed an issue where a [Job recreated with the same name as a recently deleted Job could remain unreconciled](https://github.com/kubernetes/kubernetes/pull/142247) because it inherited pending Pod expectations from the previous Job
* kubectl describe node: [per-pod resource percentages no longer print -9223372036854775808% on nodes that have not reported allocatable resources](https://github.com/kubernetes/kubernetes/pull/142215), and the "Allocated resources" totals now use the same resource accounting as the per-pod rows
* Added resource version to [eviction api](https://github.com/kubernetes/kubernetes/pull/142197)
* [LimitRanger no longer re-validates the resource requests and limits a pod resize leaves unchanged](https://github.com/kubernetes/kubernetes/pull/142171). Only the values a resize changes are checked against the LimitRange, so an existing pod is no longer rejected on resize by a constraint it already violates
* Fixed [false fractional-byte warnings for integer resource quantities larger than the int64 range](https://github.com/kubernetes/kubernetes/pull/142131)
* Out-of-tree kube-scheduler plugins using the `NominatedPodsForNode` method [must now pass `logger klog.Logger` as the first argument](https://github.com/kubernetes/kubernetes/pull/142118)
* Added support for [using PKCS#10 signing requests signed with ML-DSA keys](https://github.com/kubernetes/kubernetes/pull/142196) in CertificateSigningRequest, gated by the CertificateSigningRequestMLDSA feature-gate
* kubeadm: [added support for the ML-DSA encryption algorithm](https://github.com/kubernetes/kubernetes/pull/142037). "ML-DSA-44",  "ML-DSA-65" and "ML-DSA-87" are now allowed values for ClusterConfiguration.EncryptionAlgorithm for new clusters using the v1beta4 and the still disabled (WIP) v1 API
* Fixed [DRA kubelet plugin helper rolling updates for drivers with long valid names](https://github.com/kubernetes/kubernetes/pull/142003) by shortening automatic DRA service socket paths when needed
* The documentation of `Node.status.volumesAttached[].devicePath` now [states the platform-specific semantics](https://github.com/kubernetes/kubernetes/pull/141861): on Linux it is the host block-device node, on Windows it carries the CSI VolumeID
* Fixed a [race in client-go MutationCache indexed lookups](https://github.com/kubernetes/kubernetes/pull/141736) that could temporarily hide a recently created replacement object
* Both [`distribute-cpus-across-cores=true` and `align-by-socket=true` options were enabled](https://github.com/kubernetes/kubernetes/pull/141238), even when a single socket had sufficient capacity
* Fixed a bug where[ kubelet logged `--manifest-url-header` credential values](https://github.com/kubernetes/kubernetes/pull/140220) (e.g., Authorization tokens) to runtime logs at startup. Only header key names are now logged
* kube-apiserver: added the alpha [`ManagedFieldsOptOut` feature gate](https://github.com/kubernetes/kubernetes/pull/139561) (off by default)
* kube-apiserver: Requests to unknown `/apis/...` paths and final delegation 404s now [return a JSON `Status` object with `Content-Type: application/json` instead of a plain-text "404 page not found" body](https://github.com/kubernetes/kubernetes/pull/138219)
* Fixed a [bug where kubelet device manager may assign the same device ID to multiple pods](https://github.com/kubernetes/kubernetes/pull/137534) simultaneously

## Deprecated
* Removed the [deprecated `WindowsHostNetwork` feature gate](https://github.com/kubernetes/kubernetes/pull/142018) (KEP-3503, withdrawn). The gate no longer guarded any code paths
* Removed the [`SeparateTaintEvictionController` feature gate from `kube-controller-manager`](https://github.com/kubernetes/kubernetes/pull/141789). Remove this gate from existing `--feature-gates` configuration before upgrading
