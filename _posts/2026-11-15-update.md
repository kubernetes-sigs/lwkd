## Subprojects and Dependency Updates

* [cri-o v1.37.3](https://github.com/cri-o/cri-o/releases/tag/v1.37.3): Fixes kata shim crash loops, fixes seccomp notifier fd leak and exclusive CPU cleanup; also [v1.36.8](https://github.com/cri-o/cri-o/releases/tag/v1.36.8), [v1.35.11](https://github.com/cri-o/cri-o/releases/tag/v1.35.11)
* [ocicni v0.6.0](https://github.com/cri-o/ocicni/releases/tag/v0.6.0): Require Go 1.26.8, roll back partially attached networks, more robust config monitoring
* [cluster-api v1.14.4](https://github.com/kubernetes-sigs/cluster-api/releases/tag/v1.14.4): Bumps Go to 1.26.10, fixes KCP in-place updates, fixes clusterctl listing of List kinds; also [v1.13.8](https://github.com/kubernetes-sigs/cluster-api/releases/tag/v1.13.8)
* [prometheus v3.16.0](https://github.com/prometheus/prometheus/releases/tag/v3.16.0): smoothed/anchored selectors now stable, adds experimental query-cost limits, fixes HTTP/2 negotiation under Go 1.27+
* [kops v1.37.0](https://github.com/kubernetes/kops/releases/tag/v1.37.0): Kubernetes 1.37 support, smaller nodeup bootstrap, remove gossip DNS; also [v1.36.3](https://github.com/kubernetes/kops/releases/tag/v1.36.3)
* [cluster-autoscaler v1.36.2](https://github.com/kubernetes/autoscaler/releases/tag/cluster-autoscaler-1.36.2): Fixes CVE-2026-111943 (Go x509) by rebuilding images, fixes AWS memory overflow, fixes GPU quota blocking scale-up; also [v1.35.3](https://github.com/kubernetes/autoscaler/releases/tag/cluster-autoscaler-1.35.3), [v1.34.6](https://github.com/kubernetes/autoscaler/releases/tag/cluster-autoscaler-1.34.6)
* [grpc v1.81.2](https://github.com/grpc/grpc/releases/tag/v1.81.2): Updates gRPC repo roots, fixes Windows use-after-free error, fixes ARM completion queue race; also [v1.80.1](https://github.com/grpc/grpc/releases/tag/v1.80.1), [v1.78.2](https://github.com/grpc/grpc/releases/tag/v1.78.2)
