## Release Schedule

**Next Deadline: [Docs Freeze](https://github.com/kubernetes/sig-release/blob/master/releases/release_phases.md#docs-freeze), [December 3 (AoE)](https://github.com/kubernetes/sig-release/tree/master/releases/release-1.38#timeline)**

With Code Freeze in effect, only release-blocking issues and PRs are being considered for the v1.38 milestone. Feature blog PRs should be ready for review by November 30, ahead of Docs Freeze.

The Release Team has [clarified the freeze exception policy](https://github.com/kubernetes/sig-release/blob/master/releases/EXCEPTIONS.md), including stricter submission windows, confirmed review plans, and a matching thread in the #sig-release Slack channel.

The December patch release cherry-pick deadline is December 4, with releases targeted for December 8.

Patch releases [1.37.3](https://github.com/kubernetes/kubernetes/blob/master/CHANGELOG/CHANGELOG-1.37.md#v1373), [1.36.7](https://github.com/kubernetes/kubernetes/blob/master/CHANGELOG/CHANGELOG-1.36.md#v1367), and [1.35.11](https://github.com/kubernetes/kubernetes/blob/master/CHANGELOG/CHANGELOG-1.35.md#v13511) are available. Versions 1.37.3 and 1.36.7 were built with Go 1.26.11.
